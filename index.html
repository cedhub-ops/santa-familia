            Participants

            Familles & exclusions

            🏠 Familles

            Les membres d'une même famille ne se tirent jamais entre eux. Choisis la famille de chacun dans la liste des participants, puis donne une couleur à chaque famille.

            🚫 Exclusions

            Pour aller plus loin : entre deux personnes, entre une personne et toute une famille, ou entre deux familles.

            ⇄

              Événement

              Affichés sur l'accueil, avec un compte à rebours dans les notifications la dernière semaine.

              Notifications

              Message à tous

              Apparaît dans la cloche 🔔 de chaque participant.

              Automatiques

              Chaque participant voit aussi dans sa cloche :

              • ses tâches à faire (liste vide, aucune idée pour les autres) tant qu'elles ne sont pas faites ;
              • l'annonce du tirage ;
              • les nouvelles idées pour sa personne secrète (sans dévoiler qui) ;
              • le compte à rebours la dernière semaine.

              Pour relancer les retardataires (pastilles orange ci-dessus) hors de l'app : bouton « 🔗 Lien perso » → WhatsApp.
